# ReviewAnalyzer — ML-сервис анализа тональности отзывов

##  Актуальность
Автоматическая обработка пользовательских отзывов и комментариев критически важна для e-commerce, медиа-платформ и служб поддержки. Ручная классификация занимает часы, субъективна и не масштабируется. ReviewAnalyzer решает задачу мгновенно: принимает текст, определяет эмоциональную окраску (positive/negative/neutral) и возвращает структурированный результат с меткой уверенности. Это позволяет бизнесу строить аналитику в реальном времени, быстро реагировать на негатив и автоматизировать маршрутизацию обращений.

## Функциональные требования
1. REST API на FastAPI с автоматической OpenAPI-документацией (`/docs`)
2. Регистрация и аутентификация пользователей через JWT (OAuth2 Password Flow)
3. Приём текста на анализ: `POST /api/v1/analyze`
4. Асинхронная обработка через Celery + Redis, возврат `task_id`
5. Получение статуса и результата задачи: `GET /api/v1/tasks/{task_id}`
6. Сохранение истории запросов и результатов в PostgreSQL (async SQLAlchemy)
7. Валидация входных/выходных данных через Pydantic-схемы
8. Управление версиями схемы БД через Alembic-миграции

## Нефункциональные требования
- Время ответа API < 500 мс (без учёта ML-инференса)
- JWT-токен с TTL 30 минут, пароли хешируются через bcrypt
- Покрытие тестами ≥ 60% (`pytest` + `httpx`, фикстуры, `dependency_overrides`)
- Контейнеризация: `docker compose up` поднимает 4 сервиса (api, worker, db, redis)
- Воспроизводимое окружение через `uv` + `pyproject.toml` + `uv.lock`
- Логирование запросов и ошибок, healthcheck для всех контейнеров
- Stateless-архитектура, соответствие принципам REST (RFC 7231)


### Стек технологий
| Компонент | Технология | Назначение |
|-----------|------------|------------|
| Web-фреймворк | FastAPI + Uvicorn | Async REST API, автодокументация |
| БД | PostgreSQL + SQLAlchemy (async) | Хранение пользователей, задач, результатов |
| Миграции | Alembic | Версионирование схемы БД |
| Аутентификация | JWT + passlib(bcrypt) | Stateless-токены, безопасное хранение паролей |
| Очередь задач | Celery + Redis | Вынос долгого ML-инференса из HTTP-потока |
| ML-ядро | scikit-learn / fasttext | Классификация тональности текста |
| Тесты | pytest + httpx | Изолированное тестирование с моками |
| Зависимости | uv + pyproject.toml | Быстрая и воспроизводимая установка пакетов |
| Инфраструктура | Docker Compose | Единый запуск всех сервисов |
